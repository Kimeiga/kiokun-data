# Open Graph fonts

`noto-sans-sc-og.woff2` and `noto-sans-kr-og.woff2` are 400-weight WOFF2
subsets of the canonical Noto Sans CJK SC and Noto Sans CJK KR fonts published
by the [Noto CJK project](https://github.com/notofonts/noto-cjk).

The SC build covers the unified CJK, compatibility, radical, stroke, kana,
Bopomofo, and supported supplementary ideograph ranges. The KR build covers
modern Hangul, Jamo, and compatibility Jamo. This gives the server-side Open
Graph renderer broad Chinese and Korean coverage with one asset request per
family.
